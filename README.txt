The opening page, monogram, invitation wording, date page, venue placeholder,
countdown, blessing page, Tap to Reveal interaction, and background music have
been kept as in the approved version. The only design adjustment in this

and the original four photos, without AI face edits or photo retouching.

VERCEL DEPLOYMENT (NO GITHUB REQUIRED)
1. Open https://vercel.com/drop in Safari.
2. Sign in to your Vercel account (or create one).
3. Upload this ZIP file directly. It is already arranged with index.html at
   the ZIP root, so you do not need to re-zip or move files.
4. Choose your Vercel team, enter a project name, and tap Deploy.
5. When deployment finishes, open the generated .vercel.app URL to check it.

Note: Vercel Drop creates a new project for each upload. If you later want to
update the same project URL, connect a Git repository or deploy updates with
the Vercel CLI. iPad Safari may block audible autoplay; the first Tap to Reveal
gesture starts the background music.
